# 🏃 Sprint Analyzer

Streamlit-приложение для анализа спринтов из Jira. Позволяет визуализировать задачи, отслеживать прогресс, анализировать нагрузку команды и создавать задачи через JSON.

## 📋 Возможности

### 🏃 Анализ спринта
- **Подключение к Jira** через Bearer Token (PAT)
- **Выбор спринта** из списка или ввод названия вручную
- **Метрики спринта**: всего задач, выполнено, в работе, оценка/залогировано
- **Анализ по статусам** с группировкой и прогресс-баром
- **Статистика по исполнителям** с распределением задач
- **Сводные таблицы** по типам и статусам
- **Фильтрация** задач по статусу, исполнителю и типу

### ➕ Создание задач
- **Массовое создание задач** в Jira через JSON
- Поддержка полей: summary, description, issuetype, priority, labels, assignee, epic_link, components
- Отчёт о результатах с ссылками на созданные задачи

## 🛠 Установка

### Требования

- Python 3.11+
- Poetry (рекомендуется) или pip

### С Poetry

```bash
# Клонировать репозиторий
git clone <repo-url>
cd sprint-analizer

# Установить зависимости
poetry install

# Активировать виртуальное окружение
poetry shell
```

### С pip

```bash
pip install streamlit pandas pypdf python-dotenv
```

## ⚙️ Настройка

Создайте файл `.env` в корне проекта:

```env
JIRA_API_TOKEN=ваш_токен
JIRA_BASE_URL=https://jira.example.com
```

### Получение API токена

1. Откройте Jira → Профиль → Personal Access Tokens
2. Создайте новый токен с правами на чтение и создание задач
3. Скопируйте токен в `.env`

## 🚀 Запуск

```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`

## 📊 Использование

### Навигация

В боковой панели расположены:
- **Меню** — переключение между разделами «Анализ спринта» и «Создание задач»
- **Подключение / Отключение** — управление соединением с Jira

### Анализ спринта

1. Нажмите **«Подключиться»** в боковой панели
2. На странице анализа выберите спринт из списка или введите название
3. Нажмите **«Загрузить»**
4. Используйте вкладки:
   - **По статусам** — задачи сгруппированы по статусу
   - **По исполнителям** — нагрузка на каждого члена команды
   - **Сводная** — таблица по типам и статусам
   - **Все задачи** — полный список с фильтрами

### Создание задач

1. Переключитесь на **«Создание задач»** в меню
2. Подготовьте JSON с описанием задач (формат см. в приложении)
3. Вставьте JSON и нажмите **«Создать задачи»**

Пример JSON:

```json
{
  "jira_config": {
    "project_key": "TEST"
  },
  "tasks": [
    {
      "summary": "Название задачи",
      "description": "Описание задачи",
      "issuetype": "Task",
      "priority": "Medium",
      "labels": ["label1"],
      "assignee": "username",
      "epic_link": "EPIC-1",
      "components": ["Backend"]
    }
  ]
}
```
